# 架构与维护说明

## 数据流

```text
本地 HTML/JS
  ⇅ Qt WebChannel（JSON 请求，不监听网络端口）
Qt 主进程
  ⇅ multiprocessing.Queue
解析子进程
  ├─ SQLite：卡牌、资源、资源包扫描状态、收藏
  ├─ UnityPy：AssetBundle / SerializedFile
  ├─ Pillow：纹理 → PNG
  └─ FMOD + libsndfile：AudioClip → PCM WAV
```

GUI 与原生资源解码隔离。普通解析进程与独立特效进程各自拥有 Unity 对象和 SQLite 连接，避免 UnityPy 对象跨线程使用。特效解析由宿主路由，支持取消与 30 秒超时；公开字幕查询在独立线程等待网络，不访问 Unity/SQLite 对象。索引生成器每完成一个资源包就让出执行权，搜索 / 普通预览请求在包与包之间处理。长时间的单包解压、卡牌全部声音解析和批量导出仍可能让后续后端请求等待，但界面不会失去响应。

关闭窗口先发送退出消息，等待 1.5 秒；若原生解码仍忙则终止子进程，最多再等 2 秒。Windows Job Object 把桌面与后代进程置于同一生命周期；控制台被关闭时，操作系统清理后代。系统不支持作业对象时会写出警告，窗口关闭仍有显式清理。QLockFile 避免同一个工作区重复启动桌面实例。

## 资源解析

1. `asset_manifest.unity3d`：读取 cards_map、基础 GUID catalog、bundle_deps。
2. `asset_manifest_<locale>.unity3d`：读取 baseGuid 到语言 GUID / bundle 的覆盖映射。
3. `dbf.unity3d`：读取 CARD 文本、CARD_HERO 皮肤元数据；不用网络版本替代本地版本。
4. CardDef：遍历 GameObject 的全部组件，按字段识别定义，不依赖“第二个组件一定是定义”。
5. 兼容当前 `Golden` 字段及旧 `Premium` 字段，记录普通、金卡、异画、钻石资源。
6. 预制体：按真实 PPtr 的 fileID / pathID 走引用图；外部 CAB 通过依赖表定位。跳过脚本 / 父 Transform 回链；已访问集合避免循环。超过 4,000 个对象报未完成，不悄悄截断成功。
7. 音频：定位本地实际语言资源；完整读取 `AudioClip.samples`，每个子采样分别转换成 PCM WAV。不是简单修改扩展名。

音效分类采用可解释规则，不使用模型猜测。名称含 `VO_`、voice、dialog 等归到角色语音；music/stinger 归音乐；界面 / 环境 / 战斗随后匹配；无法判断保留“其他音效”。分类是检索辅助，不是官方语义标签。

## 性能与存储

- 缓存按游戏路径、关键清单及 DBF 大小与纳秒时间戳生成快照指纹。
- SQLite 使用 WAL，按单包事务更新。扫描标记带大小、修改时间、错误文本；成功且未变化的包不重读。
- 资源包 LRU 最多保留 4 个环境，避免把几千个 Unity 环境永久保留。
- 卡牌列表分页；图像懒加载；最多 2 个缩略图请求在途；详情和列表均检查请求代数，旧请求不覆盖新页面。
- WAV / PNG 按 CAB + pathID 缓存。索引预览不会一开始解码所有音频。
- 每次导出创建独立时间戳目录，原文件不被覆盖。`export-report.json` 列出来源快照、文件和失败项。
- 音频波形由解码后的真实 PCM 采样计算，浏览器无需为绘图重复读取长音轨。

收藏目前属于对应的本地快照；更新后新快照不会自动迁移收藏。缓存没有自动按容量淘汰；可以在关闭工具后手动删除 `workspace/cache` 中不再使用的旧快照。勿删除导出目录中的作品。

## 特效边界

二维预览解释粒子的起始寿命、速度、尺寸、颜色、发射率、Burst、基础形状半径、重力、尺寸曲线、颜色渐变与纹理表格采样。预览只说明资源大致构成，不保证 Unity 逐像素还原。

目前没有实现 Transform 完整三维层级、模型骨骼、动态 Shader、材质混合语义、事件 / 条件调度、目标寻路与游戏动画脚本。关联音频可以选择一条与预览同时启动，不能冒充游戏的完整时间线。

若后续要求完整特效，应建立可独立验证的 Unity 兼容预览运行时，并逐项实现客户端所需的 Shader、脚本触发和动画依赖。仅继续给 Canvas 添加通用粒子动画不能完成这项需求。

## 错误与维护

所有游戏路径仅用于读取。输出不允许落到游戏目录内；媒体导出源限制在当前快照生成的文件内。SQL 使用参数，HTML 展示内容转义，GUI 不加载远程页面。唯一外部链接为作者主页。

遇到新客户端结构时，先运行 `tools/probe*.py` 在 `.cache` 保存摘要，再调整 Unity 适配层。不要用忽略所有异常的方式把“无法解析”变成“没有资源”。新字段需保留原始路径以便复查。

本轮交互、特效隔离和公开字幕的详细约束见 [交互修复](INTERACTION_FIXES.md)。
