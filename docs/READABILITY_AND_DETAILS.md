# 筛选记忆、卡牌详情与显示设置

本次更新不新增运行依赖，继续使用 Python、PySide6 / Qt WebEngine、SQLite 和现有音频库。首次启动会自动升级图鉴元数据索引；收藏、原始资源及已有导出继续保留。

## 语音整体导出

在卡牌详情的「语音」页，新增「导出时合并已勾选音效」。默认关闭，独立记忆。

- 关闭：维持原始声音导出行为。
- 开启：逐条导出、播放器 WAV 按钮、「导出全部角色语音」和整卡导出中的角色语音，都会根据「配套音效 / 音乐」「通用音效」勾选状态生成合并 WAV。
- 配套音效仅取同一事件组；通用音效沿用已有种族、材质、落地、初始关键词规则。同一素材只混入一次。
- 一个原语音子采样生成一个 WAV，不把不同台词串成一条。配音同时起播，保留尾声，最多 15 秒；主语音不会被 15 秒上限裁切。这与现有试听的近似时序一致，不复现游戏触发逻辑。
- 输出 PCM 16-bit；使用各输入中的最高采样率。采样率不同时用线性插值上采样，单声道可扩展到双声道；超过满幅时统一衰减以避免削波。原素材导出仍保持原采样率、声道与全部子采样。
- 缺失配音会写入导出报告，并导出已解析的部分。没有可合并配音时保留原声。当前混音支持单声道／双声道；更多声道的素材应关闭合并导出。
- 整卡导出仍包括原有的图像、文本和独立音效文件；只导出语音整体时使用新增「导出全部角色语音」。

`export-report.json` 记录每个合并文件的输入轨道、采样率、声道和峰值衰减，方便追查素材来源。连续导出目录改用随机后缀，修复 Windows 相同时钟刻度下目录名碰撞的问题。

## 搜索与筛选

卡牌、英雄、声音、特效四个页面分别保存搜索词、语言、收藏筛选、分类、组合筛选和图鉴排序。切页时不会互相覆盖，重启从 `workspace/settings.json` 的 `view_state` 恢复。

搜索条件即时提交保存；搜索结果继续使用原有 280 ms 防抖和中文输入法处理，不会每输入一个字就重新查询资源。临时多选和分页位置不持久化，切页从当前条件的第一页开始。

工具栏「重置搜索与筛选」及图鉴「重置筛选」清空当前页的搜索、筛选和排序，不影响其他页或真实收藏记录。语言回到设置中的默认语言。

## 卡牌详情

以下为该版本的历史说明；当前布局已将基础信息移到底部，并移除赛制与打造／分解展示，详见 [图鉴卡片与详情布局](CATALOG_CARDS.md)。

- 展示法力、类别、稀有度、职业、多种族、攻击／生命、武器耐久、系列及赛制。零费、零攻击不当作缺失值。
- 相关牌来自客户端 `RELATED_CARDS`，同时展示正向关系及来源卡。点击跳转后可逐级返回，恢复标签、品质、语音语言及侧栏位置。
- 客户端关系表并不覆盖所有历史卡牌；无记录时明确说明，不根据名称或卡牌 ID 相似度伪造衍生关系。
- 标准赛制沿用本地系列和轮换年份参考，不声称实时读取服务器规则。不可收集的衍生牌可能没有构筑赛制标记。
- 打造／分解显示普通和金卡的常规奥术之尘参考；核心借用、不可收集、免费或明确不可打造的记录显示不可用。旧卡金卡没有独立活动覆写时展示常规金卡参考。离线数据无法确认账号限制或限时全额返尘。
- 常规价格参考[暴雪打造说明](https://hearthstone.blizzard.com/en-us/news/10245930)与[官方卡牌库](https://hearthstone.blizzard.com/en-us/cards/39426-arcane-giant/)。这些说明仅用于实现时核对，详情不发起价格网络查询。

规则文本提前展示，提高字号与行距，保留加粗关键词和斜体。所有文本先转义，只恢复不带属性的 `b`、`i` 和 `br` 标签，避免将客户端文字当作任意 HTML 执行。预览原画缩到约 200 px 高，完整卡面缩到约 340 px 高；点击查看大图及原始尺寸 PNG 导出保持不变。

## 字体与缩放

「资源与设置 → 显示与阅读」提供：

- 界面缩放：80%–140%，以 5% 为步长。
- 字体缩放：85%–150%，以 5% 为步长。
- 「恢复 100%」同时重置两项，退出后保留设置。

界面使用 Qt 原生页面缩放，避免 CSS 变换导致弹窗与点击坐标偏移。文字字号统一使用根字号比例；字体缩放不会同比放大图像。系统字体按 Segoe UI Variable、Segoe UI、微软雅黑、苹方、Noto CJK、通用 sans-serif 回退，不联网加载字体，不依赖开发机额外安装的商业字体。

增强小窗口换行、文字对比度、键盘焦点和减少动态效果偏好。长卡牌列表对屏幕外卡片延迟绘制，沿用两项在途的缩略图队列和现有缓存。
