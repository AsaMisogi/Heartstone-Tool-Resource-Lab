# 启动修复与台词多来源（2026-09-22）

## 启动

中文 BAT 之前调用了缺失的 `Start-PengPengWorkbench.bat`，因此窗口一闪即逝。现已补齐该兼容入口，固定工作目录为工具所在目录，优先使用项目 `.venv`；没有环境时按锁定依赖创建。启动出错会显示错误并暂停，正常关闭自动退出。中文入口和英文入口均可传递命令行参数；不要只复制单个 BAT 到别处使用。

双击项目根目录的 `启动砰砰解析台.bat` 即可。依赖损坏使用 `Install-Dependencies.bat` 修复。

## 设置方法

进入 **资源与设置 → 按需补充公开台词**。

- 总开关控制后续公开查询；每个来源也可独立勾选。
- 按显示顺序查询，用“上移”调整优先级。失败、未收录、仅收录部分事件时，继续查询后续已启用来源。已补齐即停止。
- 自定义来源支持添加、编辑、删除；所有开关、顺序和配置自动保存到 `workspace/settings.json`，重启保留。修改后重新打开卡牌语音页生效。
- 本地字幕始终优先。精确音频键可匹配带序号的独立分支；Wiki 只补充双方各自唯一的登场、攻击、死亡事件。原卡元数据来自已核对的声音引用。
- 台词下方保留具体来源链接，查询提示分别列出各源补充数量或失败原因。通用音效与配套音乐的独立开关不受影响。

## 内置来源与真实覆盖

默认顺序为 **百度百科 → 灰机 → HearthSim hsdata → Wiki.gg 中文**，后两项默认关闭。旧设置首次升级也将后两项关闭并移到末尾；之后保存的用户开关与排序不再重置。关闭公开查询总开关或关闭全部来源会继续保持关闭。仍缺失的文字可由独立开关控制的离线语音识别补充，见 [语音识别说明](SPEECH_RECOGNITION.md)。

| 来源 | 接入方式 | 本次实测 |
| --- | --- | --- |
| HearthSim hsdata | GitHub 原始 `Strings/zhCN/GAMEPLAY_AUDIO.txt` | 读取 17,744 个精确键；表中没有火车王 EX1_116 台词，不按卡牌名称猜测 |

hsdata 是从客户端提取的字符串快照，并不是完整随从台词库。本地字幕优先，远程按完整音频键精确匹配，保留序号和条件分支。Wiki 来源仅补充双方各自唯一的登场、攻击、死亡事件；不将故事、属性、英文台词或随机多条分支当成准确简中台词。

### 重试获取缺失台词

简中语音页存在缺失台词且联网总开关开启时显示重试按钮。请求期间显示“正在查询台词…”并禁用重复点击；失败后恢复可点，部分补齐后仍可继续重试。切卡或切换语言时丢弃旧请求结果。

重试绕过本轮来源缓存（包括空结果）和短冷却，重新查询当前启用来源；不会删除成功缓存或覆盖已有字幕。网络仍失败时可回退带“离线缓存”标记的旧成功数据。总开关关闭不发起新查询。语音播放、逐条导出和配套音效与此请求独立。

普通 Wiki 成功缓存保留 30 天，空结果保留 1 天；hsdata 整表缓存 1 天，由所有卡牌复用。请求失败不写空缓存。当前 hsdata 远程补充只读取简中 GAMEPLAY_AUDIO；本地仍读取已有多语言字符串表。

## 自定义接口协议

自定义是数据接口适配，不是“填任意网页就自动理解台词”。支持 HTTP(S)，不支持账号密码嵌入 URL、脚本解析、文件协议。填写名称、格式和 URL 模板即可。最多配置 16 个来源（包括内置来源）。

支持占位符（替换值自动 URL 编码）：

| 占位符 | 含义 |
| --- | --- |
| `{dbfid}` | 经过原卡引用核对后的 DBF 编号 |
| `{cardid}` | 同一原卡的卡牌 ID，例如 EX1_116 |
| `{name}` | 同一原卡的中文名称 |
| `{locale}` | 当前台词语言，目前为 zhcn |

模板必须包含前三者之一，且不能放在域名中。

### JSON 格式（推荐）

例如 `https://你的站点/quotes/{dbfid}?locale={locale}`，响应为 UTF-8 JSON：

```json
{
  "dbfid": 724,
  "locale": "zhcn",
  "quotes": {
    "Play": "登场台词",
    "Attack": "攻击台词",
    "Death": "死亡台词"
  }
}
```

编号与语言必须和请求一致；quotes 允许缺少任意事件，没有收录时返回 `{}`。值必须是非空字符串，最多 2000 字。不要把多个随机分支合并成一个字符串。接口提供者负责文字准确性；来源解析不生成或翻译台词；后续离线语音识别另行标记，不混入该来源。响应中的额外网页链接不被采用，归属链接使用实际请求地址。

### MediaWiki 格式

例如 `https://你的维基/api.php?action=parse&page=Card/{dbfid}&prop=text&format=json&redirects=1`。要求响应具有 `parse.text["*"]`，HTML 内是灰机式“台词”二级标题、“登场 / 攻击 / 死亡”事件标签和 blockquote。不是所有 MediaWiki 站点使用相同模板，布局不同需要增加适配器，不能仅改变网址。

## 缓存与维护

灰机继续兼容旧缓存与隔离浏览器保存结果；其他来源存于 `workspace/cache/transcripts-v3`。缓存键包含完整来源配置和卡牌请求地址，修改接口不会误用旧接口缓存。非空结果缓存 30 天，空结果 1 天；网络错误不记为空台词。请求失败时可使用该来源已存在的成功缓存，并显示离线标记。停用来源后不读取其缓存。单次请求超时 8 秒，Wiki / 自定义响应上限 2 MB（灰机 1 MB），hsdata 整表上限 8 MB；403/429 冷却一分钟，只影响该来源。网络工作仍在独立线程，不阻塞本地音频解码与播放。
