# 本地百科与资源展示（0.8）

## 数据来源与升级

原始资源、卡牌 ID、DBF 标签来自用户安装的客户端。百科目录版本升级时重新读取
CardDef、声音条件和 DBF 产品表，数据库按安装/补丁指纹隔离；不会删除收藏与导出。
首轮关系构建在本机约两分钟，后续打开复用 SQLite。进度显示在界面任务条。
图鉴翻页不读取 Unity 文件；原画和声音按需解码。

`catalog.py` 负责 DBF 筛选，`encyclopedia.py` 负责版本组、批次、词条与反向语音关系。
这些数据都是可重建缓存，不应随发行包分发。

## 同名版本与关系

默认按中文名称、普通原画 GUID、英雄类别、卡牌类型、战棋等级和金色标记分组。名称相同但图不同的
英雄皮肤仍分开。奇利亚斯豪华版 3000 型的构筑外观是一个已核实的特殊集合，
单独分为一组；不能把所有 `t` 后缀都当成外观，因为大多数是有独立规则的衍生牌。

筛选先执行，之后分组、排序、分页，因此系列筛选和收藏会选中对应的真实版本。
详情“同名版本”显示整个组的 ID、模式参考、系列与规则文字，可以逐个打开原画、
语音和源数据。精确输入完整 ID 可定位指定版本。收藏仍按原始 ID 保存。

衍生关系首先使用 RELATED_CARDS 和战棋伙伴/普通金色引用标签；此外，具有明确生成
语义、且名称能唯一定位的非收集卡也会加入关系表，同名版本共享已知关系。
`card_relations.py` 用最长名称匹配避免子串重叠，歧义时不猜测。神器、神奇宝藏、
卡扎库杉宝藏以核实的成员集合补全；文本对象通过安全 DOM 替换成为跳转按钮，多个
对象打开带缩略图的选择窗。不会用模糊相似词自动补关系。关系可双向浏览，详情提供
返回按钮，恢复原先页签、品质和滚动位置。

## 专属语音和场景角色

法术的声音预制体中有 `m_CardSpecificVoDataList`，其中的卡牌 ID 或
`m_RequireTag / m_TagValue` 描述实际角色条件。建立索引时将条件与英雄 GameTag
连接，因此能识别共享同一角色标签的多个皮肤，例如瓷娃娃斯嘉丽与邪爆。
只将 SOURCE（3）、HERO 区域（2）条件反向关联到说话英雄；TARGET 和 OPPONENT
仅表示触发对象，不应被当成说话者。枚举来自客户端 SpellPlayerSide / SpellZoneTag，
不能套用其他日志枚举。`voice_conditions.py` 负责条件展示、对象列表及真实事件筛选。
Unity 遍历携带条件上下文，声音路由组件仅沿显式分支，AudioSource 仅补读同宿主的
SoundDef；不沿整棵场景树扫入兄弟条件或备用角色。默认声音与条件声音分开保留。
专属声音只读取对应英雄满足的条件分支，专用登场音乐优先于同场景备用声音。
英雄页增加这些条件语音，法术详情则反向显示对应英雄。预制体中仍可能存在
客户端未安装的资源，错误会保留在可展开诊断中。

英雄图鉴的“调酒师与旅店老板”入口来自 BATTLEGROUNDS_GUIDE_SKIN；全局旅店老板
使用明确标注的工具内实体。调酒师角色键来自其选中语音配置。场景语音首次打开时
读取目标语言 AudioClip 元数据，已建立完整索引的包不会重复扫描，不解码全部音频。
名称规则可能覆盖该角色跨模式使用的台词，界面统一标注为“场景 / 全局台词”。

## 发行批次和词条

通过 MINI_SET → DECK → DECK_CARD 的实际成员建立补充系列；其记录目前同时包含
迷你系列、职业系列和部分单独合集。取成员的主要 CARD_SET 作为父系列，在筛选里
显示缩进子项。旧冒险模式依然使用原 CARD_SET，未来未知父系列保留原枚举编号。
不依据卡包售卖策略、卡牌前缀或年份臆测批次。未收录的补充系列首发日期留空，
避免把大系列日期误标为这些卡的首发日期。

词条名与解释取 KEYWORD_TEXT 和所选语言 GLOBAL 字符串。气泡显示本地补丁规则，
不依赖在线词典。客户端缺失的解释不凭空生成。文本节点以 DOM 安全方式替换，
只允许原卡牌文本中已有的无属性粗体、斜体和换行。

筛选表 `card_keywords` 由 KEYWORD_TEXT 的 `m_tagId` 映射真实卡牌标签，不从粗体
文字反推词条。种族按完整种族列表查询，支持多种族。传统卡牌与战棋分开查询，
战棋展示等级 1440、入池 1456、金色关联 1471，并保留普通/金色、伙伴等显式关联。

## 本地更新与新增标记

`game_updates.py` 管理工作区 `game-snapshot.json`，以安装清单和 DBF 状态生成指纹。
成功分析后才原子更新记录；卡牌 NEW 比较上一次已分析的目录 ID，资源 NEW 只在
新旧两次完整扫描成功后按 `(kind, locale, name)` 比较。失败或不完整索引不会把大量
旧资源误标新增。首轮没有基线就不标新增，同版重建保留本轮 NEW，下次版本替换。
卡牌收藏按 ID 迁移，资源收藏按稳定键迁移；缓存数据库只读打开且限定在工作区内。
启动、窗口获得焦点和每 60 秒检查变化，当前运行每个指纹只弹一次提示。

## 卡图与完整卡面

普通 CardDef 肖像的 Alpha 可作为游戏着色器蒙版；直接以 RGBA 展示会错误隐藏
绘画。本地原画提供两层：完整 RGB 绘画、原始 RGBA（保留蒙版）。材质图层保持
原样。无损导出不改变原始 RGBA 的像素、大小和通道。

缩略图从 RGB 生成：在小掩码上识别角落连续纯色背景，再寻找最大的无背景正方形。
处理斜边、椭圆、横竖图，不用全图删除白色的方式抠图；只裁预览，不修改原资源。
方形铺满会裁掉部分画面，可在原画页查看完整构图。缓存键升级，旧错误缩略图
不会继续被使用。

普通完整卡面按需获取 HearthstoneJSON PNG；金卡、异画、钻石按 ifindhs 实际
组件路径读取 WebM（无后缀、`_SIG`、`_DIA`）。每种品质分开缓存并限制响应大小，
错误网页不会写成媒体。动态卡面支持播放、暂停、全屏与导出，遵循减少动画偏好。
这是在线图源的最新简体中文成品卡面，不能当成本地游戏 Shader 的复现结果。

## 台词与渲染

本地字幕优先；ifindhs 是默认首选网站源，使用信息框“代码”核对身份，按完整
音频键匹配台词，不把同一事件的随机分支合并。读取失败继续尝试其他启用来源。
站点出现访问验证时，应用内独立浏览窗口正常加载页面，用户点击读取；没有
WebChannel，远程页面不能访问本地工作台 API。缓存保留原页面链接与获取时间，
网络失败可使用已有成功缓存。新版本保留全关、单源关闭和用户自定义排序。

界面移除 `content-visibility` 跳绘与 `backdrop-filter` 大面积背景模糊；保持实色
滚动表面。后台台词更新保留侧栏滚动位置，长语音列表分批显示，搜索和导出仍对
完整列表生效。动画只用于短时切换，尊重系统减少动画设置。原闪烁设备尚未实测，
不能据此宣称所有显卡上的闪烁已经消除。

0.8 开启 Chromium 原生 ScrollAnimatorEnabled，并由系统减少动画偏好控制。详情和
目录请求各自携带范围与代次；旧结果、旧异常均忽略，队列合并过期读取请求并明确
结束对应 Promise。单个复杂声音图在事件边界检查取消，Unity/SQLite 仍由同一进程
串行访问。在线成品卡面下载使用独立单线程，避免阻塞本地读取。近期音频解码结果
有界复用（32 项），播放准备状态即时显示，最后一次播放请求生效。重播显式从头
开始，失败移除缓存便于重试。关联缩略图以可见区域驱动，关闭详情释放观察器。

## 0.10 免疫词条修正

“免疫”筛选面向卡面机制，包含自身免疫、攻击时免疫，以及授予其他角色免疫。
读取本地简体卡面正文，忽略 HTML 标记，不搜索趣味描述、名字或衍生牌正文。
客户端 240 标签代表运行时不可受伤状态，不能单独用于此筛选：它会漏掉脚本
条件授予的免疫，也会收进剧情中的隐藏无敌实体。独立版本标记触发一次轻量
迁移，保留其他词条、收藏、卡牌 ID 与完整资源索引状态。

## 0.13 英雄筛选与详情宽度

英雄图鉴只保留适用的英雄筛选，移除种族和词条；前端恢复偏好、偏好校验和后端
英雄查询均清除这两个旧条件，避免升级后出现隐藏过滤。其他图鉴不变。
详情宽度保存为 `detail_width`（360–2400 逻辑像素，默认 610）。拖动松手时保存一次，
取消拖动不保存；窗口缩小时只限制呈现宽度，不覆盖大窗口偏好。
WebView2 使用 CSS zoom 坐标换算，Qt 兼容引擎使用浏览器逻辑坐标。
操作边缘提供 separator 语义、当前宽度读数、方向键和复原键。
