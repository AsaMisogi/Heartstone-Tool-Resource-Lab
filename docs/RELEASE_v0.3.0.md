# 砰砰解析台 v0.3.0

## 更新内容

- 优化首次卡牌语音读取：按 GUID／CAB 精确定位，按需解压音频与纹理数据，避免展开无关预加载依赖。
- 加快完整资源索引：减少无关资源读取，保留暂停、续扫与增量复用。
- 新增首次索引引导，可暂不建立并直接浏览卡牌。
- 主界面侧栏和设置页新增 GitHub 仓库入口，方便查看源码、反馈问题。
- 精简便携版，移除约 77.8 MiB 的 WebEngine 调试资源，保留正常运行所需组件。

## 下载与使用

下载附件 **砰砰解析台-v0.3.0.zip**，完整解压后打开其中的 `砰砰解析台.exe`。请保留同目录的 `_internal`，无需安装 Python、uv 或 Node.js。支持 Windows 10 / 11 x64，需要本机已安装炉石客户端。

从旧版升级时，先退出程序，将旧版本的 `workspace` 文件夹复制到新版 EXE 旁，可保留设置、收藏与缓存。不要把旧版 `_internal` 混入新版目录。

本地资源可离线读取；在线卡面、公开台词和首次下载语音识别模型需要联网。ZIP 不包含游戏素材、用户工作区或识别模型。

## 验证与已知限制

- 116 项单元测试通过；完成真实桌面图片、音频播放、WAV 导出、特效预览和退出清理验证。
- 本机空应用缓存实测：火车王首次语音列表约 0.29 秒、基础英雄约 0.41 秒；5,137 包完整索引约 89 秒，0 失败。实际速度受客户端、磁盘和系统缓存影响。
- 个别复杂传说皮肤仍需数秒，可能触发现有引用遍历上限；客户端缺失资源会保留诊断提示。
- 本机完成便携 EXE 启动验证，未在全新 Windows 虚拟机上验收。

实现及详细测量见仓库 `docs/PERFORMANCE.md`。发行目录内的 `SHA256SUMS.txt` 可用于校验文件。
