# 浏览、语音与特效修复（2026-09-22）

## 使用变化

1. 筛选弹层、侧栏、详情和大图滚动到边缘后，不再带动外层页面。
2. 配套音效不再随主语音结束而停止。每条配套音轨最多播放到自身第 15 秒；暂停不消耗额度。尾声期间仍可暂停、恢复、调音量或停止，选择另一条语音会停止上一组声音。
3. 列表底部显示当前页附近最多 10 个连续页码，支持输入页码后按 Enter 或点击跳转。每页可选 24、48、72、96 项，所有资源列表共用并记忆这个设置。
4. 翻页期间保留原列表高度，结果返回后原位替换。末页不足一页时保留高度，避免浏览器因为内容变短把滚动位置夹回去；重新筛选或切换页面后释放高度。
5. 设置里的“滚动加载更多”默认关闭。开启后隐藏页码，接近列表底部时追加下一批，也可点“加载更多”。切换资源类型或筛选后重新开始；查询未返回时不重复追加。
6. 语音按片段名分类，不再把包含语音的整个资源包都视为角色语音。旧索引自动升级分类，无须重新扫描全部资源包。本地字幕读取所有字符串表，并识别 COMMENT 中明确记载的音频文件别名。
7. 每条已导出语音旁保留自己的“打开导出文件夹”。同一音频再次导出时更新自己的入口，不覆盖其他音频；切换语音/音效页签后入口仍在。记录在本次会话内保存，持久化导出文件和报告的原有行为不变。
8. 特效使用独立解析进程，查询图鉴和试听不再排在特效任务之后。关闭详情或换页会取消尚未完成的解析，超过 30 秒则中止并提供重试。最近 12 个预览在进程内缓存。短促特效默认循环画面，可以拖动时间条逐帧观察；循环不重复触发关联声音。

## 缺失台词的公开来源

> 本节记录初版实现。后续已升级为展开 HTML 解析、原卡引用核对、v2 缓存和浏览验证读取；当前行为及验证边界见 [随从台词与通用音效](VOICE_UPDATES.md)。

客户端并不包含每一条随从语音的文字。本次没有内置人工编造的台词，也没有引入大模型或语音识别依赖。

- 本地字幕始终优先，已有字幕不会被覆盖。
- “按需补充公开台词”可在设置中关闭。开启时，仅在打开缺字幕的简体中文语音页后请求炉石传说中文维基（灰机）的公开 MediaWiki API。
- 用本地 DBF 数字 ID 定位 `Card/<ID>`，只向站点发送卡牌编号，不上传音频或文件路径。
- 当前适配已验证的 `台词` / `quote` 格式，匹配登场、攻击、死亡三个基础事件。只有本地事件唯一对应一条音频、来源事件也只有一条台词时才补充。随机分支、条件语音、其他语言、复杂模板和没有收录的卡牌仍保留缺失提示。
- 补充文本逐条标注来源链接与“按唯一事件匹配”；它是社区资料，不标作客户端原文。火车王 `EX1_116` 已用真实 API 验证三个事件均可补充。
- 网络在独立工作线程执行，单次请求超时 8 秒，响应上限 1 MB。界面先显示本地结果，网络失败不会阻塞播放或导出，也不会伪装成“客户端没有台词”。
- `workspace/cache/transcripts-v1` 保存台词、来源和获取时间：有结果缓存 30 天，空结果缓存 1 天；失败不写负缓存，有旧结果时允许离线回退并标注“离线缓存”。
- 台词来源并不完整，站点也可能返回 403 或临时不可用，因此不能保证所有卡牌都有字幕。重新打开语音页可以重试网络失败。

## 关键实现与约束

- `web/app.js`：请求代数防止过期列表、详情与在线台词覆盖新选择；追加页共享最多两条缩略图队列；分页偏移统一由页容量计算。
- `web/style.css`：用 `overscroll-behavior: contain` 隔离内部滚动；页码区自动换行，适配现有最小窗口宽度。
- `transcripts.py`：独立于 Unity/SQLite 的网络与字幕匹配逻辑；只解析已知简单模板，输出作为纯文本转义后展示。
- `app.py` / `worker.py`：特效进程拥有自己的 UnityReader 和 SQLite 连接；只连接已有索引，不重建图鉴或并发写设置。取消后销毁独立进程及队列，下一次请求重新创建；窗口关闭同时清理普通解析进程和特效进程。
- 媒体缓存用进程独立临时文件和完整文件发布，避免普通解析与特效解析同时生成相同 WAV / PNG 时覆盖临时文件。
- `unity.py`：不再为 `unity default resources` 等内建对象遍历整个依赖清单；二维预览只读取粒子参数与定向材质纹理，不追踪无关的形状网格、碰撞和渲染探针。
- `web/effects.js`：等待纹理加载后启动预览，修正高发射率情况下候选粒子数量的边界，支持循环画面和时间定位。

仍沿用实验性二维预览边界：不会执行 Unity 游戏脚本、专用 Shader 或完整网格动画；没有粒子系统的预制体明确提示不支持。独立进程解决的是特效任务对其他查询的阻塞，不代表普通解析队列中的大型导出和单包解压都变成并行。

## 验证方法

```powershell
.venv/Scripts/python.exe -m pytest -q
node --check pengpeng/web/app.js
node --check pengpeng/web/effects.js
.venv/Scripts/python.exe -X utf8 tools/gui_fixes.py
.venv/Scripts/python.exe -X utf8 tools/gui_workbench.py
.venv/Scripts/python.exe -X utf8 tools/gui_transcripts.py
```

`gui_fixes.py` 使用真实 Qt WebEngine 与本机客户端，检查分页、每页数量、滚动隔离样式、连续追加、公开来源、独立导出入口、自然结束后的尾声、15 秒上限、特效绘制、特效期间查询、取消和窄窗口。为明确构造“主语音短于配套声音”，尾声测试加快测试主音轨；上限测试使用 QA 目录生成的 20 秒静音 WAV。截图及结果在 `.cache/qa-fixes`，运行结束恢复设置，测试导出放在 QA 目录。

滚动隔离的自动化检查验证实际 Qt 中的计算样式，未覆盖所有鼠标驱动和触控板惯性输入。特效耗时取决于资源及缓存；本机火车王关联的三粒子系统样本，定向解析约 0.45 秒，首次启动独立进程约 1.7 秒，解析期间普通列表查询约 84 毫秒。此数据是样本验证，不是全资源性能保证。
