# 首次读取、资源索引与便携版体积优化

## 实现

- `pengpeng/bundle.py` 读取 UnityFS 的压缩目录与块表。只加载序列化对象数据；音频 `.resource`、纹理 `.resS` 提供可定位流，播放或显示时才解压命中的块。无需预先建立完整索引，也不需要预解压游戏资源。
- GUID 查询使用明确的容器映射，不调用 UnityPy 的全量预加载表展开。后者会为了反查名称遍历无关依赖、搜索文件系统，是初次卡牌读取的主要隐藏开销。
- 外部 CAB 通过依赖包的目录定位，不再依次加载依赖正文。CAB 内部直接以 pathID 查字典，保持实际引用关系，不通过声音文件名猜卡牌。
- 环境缓存最多 24 个，序列化数据预算 64 MiB（至少保留当前包）；每个包的解压块缓存最多 8 块／8 MiB。Python 对象开销和当前解压瞬时内存不包含在原始数据预算内。淘汰环境时释放块缓存，不长期持有游戏文件句柄。
- 完整索引仅对 AudioClip 读取所需类型树，其余受支持类型只读名称，不解析整幅纹理。保留每包事务、暂停／续扫、时间戳增量复用和错误记录；更新包扫描时清除旧环境。
- 现代未加密 UnityFS 使用快速路径；不支持的版本／压缩方式回退 UnityPy。损坏文件仍报告失败，不把损坏伪装成空索引。UnityPy 固定版本为 1.25.2，升级时需重新运行格式和真实资源对照验证。

## 首次引导

首次成功连接游戏且索引未完整时弹窗说明用途、耗时及暂停能力。可选择“暂不建立，先看卡牌”，也可立即开始；Esc 等同暂不建立。选择保存到工作区设置 `index_guide_seen`，重启不重复打扰。随时使用右上角“建立完整资源索引”按钮增量扫描。

## 实测与范围

2026-09-23，本机 Windows、当前已安装简体中文客户端；使用独立空工作区（应用索引／音频缓存为空，操作系统文件缓存未清空）：

| 操作 | 耗时／结果 |
| --- | --- |
| 首次建立卡牌文本与连接 | 约 4.1 秒 |
| 火车王 EX1_116 首次语音列表 | 0.29 秒，7 条 |
| HERO_01 首次语音列表 | 0.41 秒，56 条 |
| HERO_01a 首次语音列表 | 1.79 秒，62 条 |
| 首条音频解码 | 约 0.005–0.11 秒 |
| 全量索引 | 5,137 包，89.3 秒，0 失败 |

全量扫描记录来自缓存预算调整前的快速读取版本；未与旧版完整扫描做同条件计时，不能据此声称整体提升倍数。性能分析中，尚未移除预加载表展开的 HERO_01 耗时约 12 秒，移除后约 0.43 秒。

两个约 85 MiB 的真实音频包：全体对象 ID、AudioClip 类型树、新旧解码音频字节对照一致；包加载由约 0.05 秒降到 0.001–0.005 秒。此为包级局部对照，不代表整个应用启动倍数。

复杂传说皮肤 HERO_01bn 在最终缓存策略下仍约 6.7 秒，返回 198 条，并触发项目已有的 4,000 对象遍历上限提示；HERO_01a 有两条客户端清单缺失的手机特效引用。未隐藏这些诊断，也不能承诺所有卡牌均瞬时完成。

## 复现

```powershell
.venv/Scripts/python.exe -m pytest -q
node --check pengpeng/web/app.js
.venv/Scripts/python.exe -X utf8 tools/benchmark_resources.py --game F:/Games/Hearthstone --workspace .cache/benchmark-fresh --scan
.venv/Scripts/python.exe -X utf8 tools/gui_first_run.py
.venv/Scripts/python.exe -X utf8 tools/gui_smoke.py --workspace .cache/benchmark-fresh
```

性能脚本输出 JSON 到指定工作区；首次测试请使用新的工作区路径，重复使用会测到缓存与增量扫描。GUI 工具需真实 Windows 桌面环境。单元测试覆盖原始／LZMA／LZ4／LZ4HC、头尾目录、对齐、跨块随机读取、EOF、截断文件、旧格式回退以及禁止展开预加载表。

## 发行体积

PyInstaller 收集阶段排除 `qtwebengine_devtools_resources.debug.pak`，减少 81,573,852 字节（77.8 MiB）。保留正常 devtools 资源、WebEngine、所有语言包、软件 OpenGL、音频与识别运行库。继续使用 onedir，不以每次启动解压或首次联网下载运行库换取体积。功能性运行库仍占较大空间，不能直接删掉 Qt 核心来压缩发行目录。
