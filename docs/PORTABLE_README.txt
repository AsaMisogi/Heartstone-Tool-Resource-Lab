砰砰解析台 · Windows x64 免安装版

1. 将压缩包完整解压到可写目录（支持中文和空格路径）。
2. 双击“砰砰解析台.exe”。无需安装 Python、uv、Node.js 或额外 Python 包。
3. 首次启动选择包含 Data 文件夹的 Hearthstone 安装目录。

必须保留整个文件夹，尤其是 _internal；不要单独移动 EXE，也不要在压缩包内直接运行。
Windows 10 / 11 64 位；炉石客户端及所需语言包需由用户自行安装。
设置、收藏、索引、缓存、日志和默认导出文件保存在 EXE 同目录的 workspace 中。
升级时退出旧版，再将旧版 workspace 文件夹复制到新版 EXE 旁即可保留数据。

本地解析、原画、声音试听与导出可离线使用。
完整卡面、公开台词查询需要联网；默认语音识别内置中英文模型，首次使用即可离线运行。
发行包不包含游戏素材。设置中可检查模型、指定自定义 Vosk 模型或在线 API。
在线 API 的密钥在界面填写并随 workspace/settings.json 保存。

启动时的控制台用于诊断，关闭控制台也会退出程序。
遇到问题请保留控制台错误及 workspace/logs/pengpeng.log。

源码及反馈：https://github.com/AsaMisogi/Heartstone-Tool-Resource-Lab
版本见 VERSION.txt；文件校验值见 SHA256SUMS.txt。
第三方声明见 THIRD_PARTY_NOTICES.md，各依赖许可保留在 _internal 的发行元数据中。

功能与使用提示：
- 卡牌图鉴支持系列、职业、种族与词条筛选；战棋图鉴提供星级与随从池筛选。
- 英雄图鉴包含皮肤、调酒师与旅店老板。语音支持场景分组、搜索、分页和重播。
- 详情左边缘可拖动调宽并记忆；方向键调整，Shift 加速，Home 或双击复原。
- 波形可点击或拖拽定位；Esc 取消拖动，方向键跳转 5 秒，Shift 加方向键 1 秒。
- 配套和通用音效可独立开关；试听与合并导出使用相同播放计划。
- 经典炉石配乐位于声音资料库的“背景音乐 → 经典默认音乐”。
- 完整卡面支持普通 PNG 和金卡／异画／钻石 WebM，动态卡面来自在线简体中文图源。
- ifindhs 需要验证时，使用详情中的“ifindhs · 浏览读取”，验证后读取本卡台词。
- 在资源与设置中检查软件更新；游戏更新后按提示重新分析，并按需重建完整索引。
- Windows 默认使用系统 WebView2，支持高刷新率；未安装 Runtime 时自动回退到 Qt 引擎。
  设置中可查看当前引擎，选择浏览器平滑或即时滚动。

本版更新日志见“更新说明.md”。

0.14 语言功能：筛选器与资源语言默认同步，可在设置关闭。关闭后资源语言跨卡牌记忆。
语音页勾选“显示其他已安装语言”，逐种加载其他语言并嵌入同一条语音下方，支持客户端台词、试听、逐条导出；统一折叠/展开，默认展开。
“导出全部语音”仅导出主语言。语言包下载完成后重新连接即可，不必先扫描完整资源。
详细用法与排查见 LANGUAGES.md。
