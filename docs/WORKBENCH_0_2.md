# 砰砰解析台 0.2：使用与实现说明

## 启动与升级

双击根目录的 `启动砰砰解析台.bat`。英文启动入口为 `Start-PengPengWorkbench.bat`，Python 包名已统一为 `pengpeng`。窗口标题、侧边栏、关于、日志提示和打包后的 EXE 均使用“砰砰解析台”。

没有填写游戏目录时，会弹出首次引导。选择包含 `Data/Win` 的炉石安装目录；只有成功读取清单后才保存路径。已经保存路径的工作区直接连接，失效路径进入设置页。升级不删除收藏、原有设置、导出文件或索引。

## 本次 19 项需求对照

| 项目 | 使用方式 / 实现 |
| --- | --- |
| 1. 中文导出名称 | 详情导出目录为“中文名_卡牌ID_语言_时间”，文件包含中文名和资源名；音频库无角色上下文时用音频名称。 |
| 2. 快速打开目录 | 导出完成后，详情内和顶部出现“打开导出文件夹”；导出记录页同样可以打开。 |
| 3. 软件名称 | 砰砰解析台；保留旧启动文件作为兼容入口。 |
| 4. 原图清晰度 | PNG 使用原始纹理全部像素，不经过缩略图，不拉伸；显示真实宽高与纹理名，报告记录尺寸。 |
| 5. 图鉴铺满 | 缩略图去除透明及白色外缘，再用 cover 适应卡片窗口；原始导出不裁切。 |
| 6. 侧栏关闭 | 点击侧栏外遮罩、关闭按钮或 Escape；关闭后恢复原控件焦点。 |
| 7. 完整卡面 | “完整卡面”标签按需获取 HearthstoneJSON 普通卡图，包含卡框与文字，可缓存、导出。 |
| 8. 查看大图 | 点击原画或完整卡面，切换适应窗口 / 原始尺寸；Escape 先关闭大图。 |
| 9. 语音语言 | 详情语音标签有独立语言框，每次打开卡牌默认简体中文，试听与导出使用所选语言。 |
| 10. 缺失语言提示 | 实际音频包不存在时显示持久提示；文本或语言 manifest 存在不等于语音已安装。 |
| 11. 详细筛选 | 系列、赛制、职业、稀有度、0～9 / 10+ 法力、类别、收集状态；条件可组合、重置。双职业同时归入两种职业。 |
| 12. 英雄筛选 | 中立、11 个职业、敌人 / 冒险角色的顺序；独立选择包含、排除、仅显示酒馆皮肤。 |
| 13. 语音可读性 | 中文事件名称与可用台词作为主信息；文件名、源字段、语言小字显示。 |
| 14. 语音 / 音效 | 分为“角色语音”“音效与音乐”，打开卡牌默认语音。 |
| 15. 配套声音 | 勾选“配套音效 / 音乐”后，混播同一个事件定义引用的音轨；默认关闭，写入工作区设置。 |
| 16. 下拉框漂移 | 使用页面内 listbox，按视口定位；支持方向键、首字搜索、Enter、Escape；滚动 / 失焦时关闭。 |
| 17. 界面优化 | 统一深蓝、暖金与青绿色调，改进文字层级、间距、焦点、状态反馈、窄窗口和抽屉动画；遵守减少动态效果的系统偏好。 |
| 18. 软件图标 | 原创卡牌、炸弹与解析旋涡图标；SVG、PNG、16～256 像素 ICO 已接入窗口与打包。 |
| 19. 首次引导 | 空设置弹出目录向导，成功连接后保存；有设置则直接进入。 |

## 图像与清晰度

“原画”是当前安装包中的 Texture2D，不含卡框。金卡和异画还有材质图层，均可单独选择与导出。工具不会把 512×512 插值放大后标成高清；例如本机 36.6.3.55344 中火车王里诺艾普通原画为 512×512，当前安装没有 `porthigh` 独立原画包。更高清的创作原稿不一定包含在客户端里。

“完整卡面”来自 [HearthstoneJSON 图像服务](https://hearthstonejson.com/docs/images.html)，是 512 像素宽的成品普通卡图，**不是高清原画**。图源版本为在线 latest，可能与本机补丁数值、插画或字体不同；金卡动画、异画专用卡框、钻石模型不由此图源还原。离线或图源没有收录时显示错误与重试，原画功能照常使用。不会下载其他语言的声音。

只有打开完整卡面时才发出固定图源请求。后端只发送公开卡牌 ID 与语言，不发送游戏目录、卡牌列表或本地文件。PNG 下载有超时、大小限制和解码校验；成功后原子写入 `workspace/cache/<快照>/renders/<语言>/`，下次直接读取缓存。请求由解析进程处理，网页不获得任意联网权限。

缩略图白边处理单独位于 `images.py`。透明边、连续白底以及部分倾斜白边只在预览中裁去；原始导出的 PNG 保留白边、Alpha 和全部像素。这使“浏览时铺满”和“导出时保持原始素材”可以同时成立。

## 声音与语言

语言是否安装以实际带语言标记的音频包为准。完整性仍以单项解析结果为准：安装了部分中文音频包也可能缺少某一条语音，失败会显示资源原因。英语基础清单存在不会再被视为安装了英语语音。

角色语音分类使用名称以及角色/任务语音包规则，台词来自本地字符串表。有台词的片段优先显示，显示文本覆盖数量；没有台词的片段注明缺失，仍然可试听，不生成虚构台词。类似 `<死亡>` 的演出标记保留，只有已知排版标签会被去除；不规范命名的个别资源仍可能需要在音效页寻找。

配套播放根据 CardDef 中同一个事件定义（例如 `m_PlayEffectDef`）关联声音，**不根据中文事件名字把所有“登场”声音混在一起**。火车王的登场语音和登场曲即为实际验证案例。混播使用共同起点，支持一起暂停、停止、调音量和定位；不会执行 Unity 脚本的条件分支、随机选择或延时，因此是素材组合试听。普通 WAV 导出仍导出选定原始片段，不把混播结果重新压成一个文件。

## 筛选与数据维护

`catalog.py` 一次读取 CARD_TAG、CARD_SET_TIMING、CARD_HERO、BATTLEGROUNDS_HERO_SKIN，构建 SQLite 辅助表。查询绑定参数，分页前筛选，不需要为筛选读取数万张 CardDef。零费是有效条件；10+ 包含所有大于等于 10 费的资源；双职业根据 MULTIPLE_CLASSES 位掩码展开。敌人包含非收集英雄记录，酒馆英雄与皮肤使用本地关联表识别。

系列是客户端记录的所属系列，可能包含历史所属关系。**标准筛选是本地年度轮换参考**：使用 CARD_SET 标准事件、EventMap 轮换年份和核心系列；离线客户端没有服务器的启用/禁用活动开关，因此不作为当前排位合法性证明，也不提供幻变每期规则。列表中已明确标注“本地轮换参考”。狂野筛选以可收集的构筑系列记录为基础。内部、测试和未上线记录可用“收集状态”进一步排除。

辅助索引采用版本标记迁移，保留原 cards 和 favorites。更换游戏版本使用现有清单指纹隔离缓存。新增设置 `paired_audio` 默认为 false；旧设置文件自动合并默认值。

## 开发与验证

```powershell
.venv/Scripts/python.exe -m pytest -q
node --check pengpeng/web/app.js
node --check pengpeng/web/controls.js
.venv/Scripts/python.exe -X utf8 tools/gui_smoke.py
.venv/Scripts/python.exe -X utf8 tools/gui_workbench.py
.venv/Scripts/python.exe -X utf8 tools/gui_first_run.py
.venv/Scripts/python.exe -X utf8 tools/gui_transcripts.py
```

GUI 检查需要真实 Windows 桌面。`gui_workbench.py` 覆盖新功能，截图与 JSON 在 `.cache/qa-workbench/`；`gui_first_run.py` 创建独立测试工作区，验证引导、连接与再次启动，结果在 `.cache/qa-first-run/`。测试不会改游戏文件。

`tools/build_icon.py` 从仓库中的 SVG 生成 PNG / ICO，便于以后改颜色或轮廓。正式打包仍运行 `Build-Portable.bat`，输出 `dist/砰砰解析台/砰砰解析台.exe`；应携带整个输出目录。
