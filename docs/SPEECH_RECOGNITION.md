# 语音识别与模型设置

在“资源与设置 → 缺失台词自动语音识别”中选择识别方式，点击“保存语音配置”，再点击“语音模型状态检查”。修改未保存时会提示先保存。检查在独立进程运行，不阻塞界面；检查期间显示当前语言与加载阶段。即使关闭自动识别，也可手动检查。

## 三种识别方式

- **内置离线模型（默认）**：免安装包包含中文 vosk-model-small-cn-0.22 和英文 vosk-model-small-en-us-0.15。直接从程序资源目录加载，首次使用无需下载，不上传音频。必须完整解压 ZIP，不能只复制 EXE。源码开发先运行 tools/prepare_models.py。
- **自定义本地 Vosk 模型**：分别选择中文和英文的模型目录，应直接包含 am/final.mdl 和 conf/model.conf。某语言留空时使用内置模型。支持 Vosk 格式的其他小模型和大模型；Whisper/PyTorch 模型文件不能直接加载，可通过兼容 API 使用。大模型需要更多内存及加载时间。支持中文和空格路径；加载时通过独立进程的工作目录兼容 Vosk 原生库。
- **在线语音识别 API**：填写完整转写地址、模型 ID、API 密钥。支持 HTTPS，以及本机 localhost/127.0.0.1 的 HTTP 服务。请求为 multipart/form-data，字段为 file（WAV）、model、language（zh/en）、response_format=json；响应须为包含 text 字符串的 JSON。兼容此协议的自建 Whisper 服务或云端服务均可使用；不支持聊天接口及各厂商的其他私有协议。

API 密钥可在界面直接填写、显示、修改或留空清除，随 workspace/settings.json 保存，复制工作区即可迁移。环境变量 PENGPENG_SPEECH_API_KEY 可作为界面未填写时的替代来源。在线模式会将待识别语音发送给用户配置的服务商，可能产生费用；不会因离线模型失败而自动切换在线。

离线状态检查会逐个实际加载中英文模型并解码静音，可发现缺失或损坏的模型；在线状态检查会发送一秒静音，验证连接、认证、模型和响应格式，可能计费。失败时保留明确错误，可修改配置后重试。

## 识别行为

本地字幕与已启用的公开台词来源优先；仍缺文字时识别中文或英语短语音。识别文字始终标明“不保证准确性”，不会写入客户端字幕。音乐和配套音效不自动识别；笑声、特殊声线可能没有结果或识别错误。

0.5 默认首选公开来源为 ifindhs，按完整音频键匹配英雄表情与专属触发语音。
若站点要求验证，点击“ifindhs · 浏览读取”，等待页面正常显示，再点“读取本卡台词”。
同名英雄页优先尝试“（英雄）”后缀，若站点没有该页面，可以点“按原名称打开”。
只有信息框卡牌代码一致的页面才会保存，缓存可离线复用。详细来源状态默认折叠。

每条最多 30 秒、16 个子采样，支持 16–96 kHz 单/双声道 WAV。独立进程顺序处理；切卡、切语言或关闭详情可取消，闲置 15 秒退出释放内存。加载、检查和在线请求总等待上限 180 秒；离线模型加载完成后推理上限 20 秒。超时可重试，试听和导出仍可用。

识别缓存位于 workspace/cache/speech；键包含音频内容、语言及后端/模型身份。更换自定义模型或修改其文件后重新识别；在线切换地址或模型 ID 后不会复用旧结果。远端同名模型更新时可点击“重试语音识别”跳过缓存。空结果同样缓存，避免反复处理笑声等音频。

## 维护与验证

- pengpeng/speech.py：内置与自定义模型加载、离线识别、内容缓存、构建用模型下载。
- speech_api.py / speech_config.py：兼容 API 请求与配置校验。
- speech_process.py：独立进程、进度、取消、超时与闲置回收。
- tests/test_speech*.py：输入边界、配置持久化、缓存切换、离线首次运行、API 协议及失败分支。
- tools/gui_speech_settings.py：隔离工作区的真实 Qt 设置流程与模型检查。
- tools/speech_smoke.py：需要本机炉石的真实中文语音识别验证。

官方模型来源与许可见 https://alphacephei.com/vosk/models 。两个内置模型均为 Apache 2.0，许可证随发行包保留。
