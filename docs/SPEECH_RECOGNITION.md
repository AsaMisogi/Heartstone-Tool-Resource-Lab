# 缺失台词离线识别

## 使用

在卡牌或英雄的“语音”页，依次使用本地字幕、已启用的公开来源；仍缺文字的角色语音自动进入离线识别。音乐、配套音效不进入识别。每条识别结果显示 **语音识别 · 不保证准确性**，支持逐条“重试语音识别”。没有识别出文字时明确显示可能是笑声、喘息或背景音，不编造台词。

“资源与设置 → 缺失台词自动语音识别”默认开启，关闭会立即取消识别，重启记忆。它与“按需补充公开台词”是独立开关：关闭公开查询后仍可离线识别；如需完全禁止首次模型联网下载，请一并关闭语音识别。开启后重新打开语音页生效。

目前支持 **简体中文（zhcn）、英语（enus）**。其他资源语言显示不支持提示，不拿中文模型猜测外语。已有台词、试听、WAV 导出和配套音效功能照常使用。只识别总长不超过 30 秒、最多 16 个子采样的短语音；支持 16–96 kHz 单/双声道缓存 WAV。长音频或异常资源给出原因，可继续试听、导出。

## 方案与占用

采用 [Vosk](https://github.com/alphacep/vosk-api) 0.3.45 与[官方小模型](https://alphacephei.com/vosk/models)。不需要账号、API 密钥、显卡、PyTorch 或 ffmpeg，不上传游戏音频。

| 项目 | 行为 / 实测 |
| --- | --- |
| Windows 识别运行库 | 官方 wheel 下载约 14 MB；本机新增运行库及传递依赖安装后约 55.2 MiB |
| 中文模型 | `vosk-model-small-cn-0.22`，下载约 42 MB，解压约 65.1 MiB |
| 英文模型 | `vosk-model-small-en-us-0.15`，官方下载约 40 MB；仅使用英语时下载 |
| 本次新增安装占用 | 中文模型及新增运行依赖合计约 120.4 MiB；不包含已有工具和验证缓存 |
| 启动 / 关闭功能时 | 不加载识别模型 |
| 活跃识别 | 单进程顺序执行，降低 Windows 调度优先级，限制数值库线程 |
| 模型释放 | 闲置 15 秒后终止识别进程；切卡、切语言、切页签、关闭详情立即取消 |
| 超时 | 首次下载总等待至多 125 秒；模型开始加载及识别最多 20 秒，超时杀掉独立进程 |
| 失败 | 当前页自动任务暂停，给出错误与手动重试入口，避免每条语音反复下载失败模型 |

2026-09-22 在当前电脑抽样 4 条真实中文语音（2.3–3.9 秒）：推理 0.91–1.28 秒；首条包含进程启动、模型加载共 1.89 秒，其余共 1.11–1.33 秒。独立识别进程峰值工作集 248–260 MiB，已验证闲置后进程退出。上述是本机小样本，不代表所有设备、全部声线的速度或准确率。特殊声线中出现了同音误识别，例如“糟”被识别成“着”，因此始终保留准确性提示。

结果文件为 `.cache/qa-speech/benchmark.json`。本机仅有简中游戏语音，英语真实游戏语音和正式免安装发行包尚未实测。

## 安装、离线使用与维护

本次工作区已安装运行库和中文模型，直接重新启动工具即可。已有源码环境在升级文件后如提示组件缺失，运行 `Install-Dependencies.bat`。新建环境按 `requirements.lock` 自动安装依赖。

首次遇到需要识别的语音时，只从官方 HTTPS 地址下载该语言的小模型；状态提示显示下载中，本地试听仍可使用。完成后可断网识别。下载失败可点击语音识别按钮重试，不自动循环重试。下载上限 64 MiB、展开上限 160 MiB，并校验压缩包成员路径；下载和展开完成前不发布模型目录。

- 模型：`workspace/models/<模型名>/`，不打包进程序，不跟随源码分发。手动离线安装时，把官方 ZIP 中同名完整目录放到此位置。
- 识别结果：`workspace/cache/speech/`。缓存键包含完整 WAV 内容、模型版本和处理版本，游戏音频变化后不会误用旧结果。空结果同样缓存；点击重试绕过缓存。
- 识别文字保存在独立字段，不写入客户端字幕或公开来源缓存。重新查询得到准确台词后，界面优先显示准确台词。
- 需要释放模型磁盘空间时，先关闭工具，再删除对应的 `workspace/models/<模型名>` 目录；下次启用会重新下载。关闭功能本身保留模型，避免重复下载。

## 代码与验证

`pengpeng/speech.py` 负责有界下载、模型加载、流式 PCM 识别和内容缓存；`speech_process.py` 负责独立进程、超时、取消和闲置释放；桌面 Bridge 轮询交付结果。Unity 解码仍走原来的解析进程，不在线程之间共享 Unity/SQLite 对象。前端只发出一个在途识别请求，以页面代次和任务 token 丢弃过期结果。

```powershell
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe -X utf8 tools/speech_smoke.py
.venv/Scripts/python.exe -X utf8 tools/gui_speech.py
```

单元测试涵盖默认值迁移、禁用、输入边界、缓存命中、空识别、强制重试、多子采样、压缩包越界和进程超时/释放。真实资源脚本验证中文识别、内存、缓存和闲置释放；Qt 脚本验证设置、自动回退、识别标记、重试、后续准确字幕优先、关闭和取消。Qt 脚本需正常 Windows 桌面，结束恢复原设置。

## 来源默认值调整

新的默认顺序为 **百度百科 → 灰机 → HearthSim hsdata → Wiki.gg**，末尾两项默认不勾选。旧工作区首次升级也将这两项关闭并移到末尾，其他来源开关与自定义配置保留。通过 `source_defaults_version` 记录迁移，之后用户重新开启、排序均被保留。
